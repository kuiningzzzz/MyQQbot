# 主动 Agent

主会话仍由 dsh 管理。Python 的生活调度器在清醒时不断推进有限回合，复用原生推理、工具迭代、inject、Spawn 和上下文压缩。没有额外预算上限；开启 AI、聊天和主动生活后，即使没有人发言，也可能持续产生模型费用。

## 状态与消息

- 清醒：所有群聊和私聊都能进入观察，Agent 自行决定是否参与；同一聊天的消息可插入未发送的当前回合，不同场景保持发送边界。等待队列中相邻的同场景发言可合并观察，保留每位真实发送者的身份。
- 普通睡眠：默认被真实点名、引用回复、私聊、任务完成或到期唤醒。Agent 可自选事件，并筛选群／联系人及普通群消息条数。
- 深度睡眠：聊天、@、私聊和子任务结果都不能叫醒，只有到期、主人指令或 admin 强制唤醒有效。

睡眠暂停主 Agent 的后续推理，不是停止整个机器人。聊天原文仍保留30天，媒体解析、记忆维护、固定提醒和已启动的后台工作继续进行。睡眠状态、截止时间、唤醒条件和累计休息会持久化，重启不会重新开始睡满原时长。

`/ai-status` 直接返回以下三种文本之一，不调用模型，也不唤醒：

```
zzz...（正在睡觉）
zzz...（深度睡眠，叫不醒的那种）
醒着醒着，有什么事？
```

`/ai-wakeup` 仅机器人主人可用。admin 可以查看详细状态、强制叫醒、安排普通／深度睡眠；关闭整个 AI 模块会撤销进行中的会话与工作。关闭“主动生活”可回退原先的被动聊天，已有睡眠仍须到期或叫醒。

## 主动联系

许可按 `private:QQ号` 或 `group:群号` 保存，初始为空。默认时段示例为北京时间09:00至23:00，结束时间不包含在窗口内；起止相同表示全天，支持23:00至09:00这种跨午夜时段。

用户可以说“早上9点到晚上11点，无聊的话可以找我”。Agent 用 `contact_policy` 保存本私聊的时段；群聊只能管理本群。其他人的私聊和其他群不能借当前发言授权。自主回合可查看或删除许可，扩大许可须由对应会话用户提出；admin 可以直接管理全部许可。

Agent 用 `focus_scene` 选择有效许可内的目标，原生结束当前回合，下一回合绑定目标后再发消息。发送时再次校验许可和时段，避免跨过23点后仍按过期许可主动发送。没有许可时可以在自己的工作空间探索、制作文件、安排子任务或休息。真实用户发来请求时的正常回复不受主动联系时段限制。

主动任务没有人类请求者，不能借接收者恰好是主人就取得主人权限；仍沿用原有工作区和主人边界。项目状态和结果可保存在files目录。普通聊天与自主活动都由同一人设和soul管理，耗时执行仍由一次性Spawn承担。

自主创建的定时任务同样保留无请求者、非主人的来源身份；后续修改或建立任务不能借收件人取得授权。这类任务在发送固定文本或AI结果时也检查主动联系许可及当时时段，避免通过定时任务绕过发送边界。用户明确要求建立的普通提醒仍按原有定时规则交付。

## 休息合并与日志

四小时休息后只短暂检查、又休息两小时，可合并为累计六小时。提前一小时被叫醒时，第一段只计一小时；期间有搜索、制作、发送等实质活动则开始新休息段。

admin 的“AI生活与日志”展示状态变化、模型实际返回的推理与文本、原生步骤、工具调用与结果、错误、累计休息，支持类型筛选、向前翻页和实时刷新。记录通过本机子进程管道收集，存放在 `data/ai/.state/ai-activity.sqlite3`，保留30天；由现有admin登录鉴权保护。已知环境密钥会脱敏，二进制图片和不透明的模型回放签名不进入行为日志。模型没有返回的隐藏思考无法展示。

累计休息日志更新为同一条摘要；送入模型的请求会折叠已经完整结束、没有实质活动的旧休息交换，同时保留人类原话、有效工具调用关系及最新累计时长。底层dsh原始会话日志不会被篡改。

## 部署验收

本版本自动增加配置、生活状态和日志数据库，不清空原有data、记忆或主会话，也没有新增模型依赖。部署完整代码后重启即可。已有自定义help文本不会被覆盖，可在admin自行补充新指令或恢复默认帮助。

1. 在admin开启AI和聊天，确认“主动生活”已开启；查看状态及原生步骤日志。没有QQ连接或模型密钥时不会启动自主模型调用。
2. 私聊授予一个短时间的主动联系许可，在admin确认保存的QQ号、北京时间窗口和开关。
3. 让Agent安排普通睡眠，测试指定事件能叫醒、未指定事件只记录；测试按群、联系人、消息条数筛选。
4. 安排深度睡眠，连续发普通消息、@、私聊，确认均不触发模型；`/ai-status`仍可回复，非主人不能执行`/ai-wakeup`。
5. 用主人指令或admin强制叫醒，确认后续观察恢复；重启一次验证剩余睡眠和联系许可保持。
6. 检查工具日志与实际QQ回执，确认自主活动未借接收者身份获得主人权限、许可窗口外不能主动发消息。相邻纯休息应合并，有实质活动后应分段。
