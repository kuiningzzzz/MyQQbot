# 浏览器与网页操作

AI 已接入与内核同版本的官方浏览器插件：

- `@deepseek-ai/dsh-browser-use@0.2.1-rc.2`
- `@deepseek-ai/dsh-experimental-browser-use-playwright-mcp@0.2.1-rc.2`
- 上游锁定的 `@playwright/mcp@0.0.80`

插件实际执行 JavaScript、读取页面结构并操作 Chromium，支持 Vue/React 页面、链接跳转、点击、输入、选项、拖拽、标签页和截图。普通 `web_fetch` 保留，用于无需渲染的网页；浏览器不会自动替换所有 HTTP 请求。

## 使用方式

可以直接对机器人说：

> 打开 https://quininezzzz.top ，等页面加载后介绍一下我的主页。
>
> 打开这个网站，进入项目介绍，展开详情后帮我总结。

主对话仍通过 `spawn_task` 委派，后台执行者先调用 `open_browser()`。这个工具在当前任务内启用官方 MCP 连接，成功后原生浏览工具会加入后续回合的工具列表，名称形如 `mcp__playwright-mcp__browser_navigate`。非浏览任务不会启动 MCP 进程或加载整套浏览工具。主聊天、后台结果交付和记忆维护不提供浏览器入口。

执行者应按本轮工具 schema 操作，不能照抄旧版 Playwright 示例。当前版本的点击/输入等工具使用 `target`；页面快照可能只返回 `.playwright-mcp/page-*.yml` 文件链接，应先用原生 `read` 读取，再用快照里的真实元素引用操作。导航成功不代表异步数据已到齐，必要时使用等待、刷新快照再读取；不要只凭首页空壳宣布无法访问。

截图可以保存到当前会话 `files_directory`，再用 `read_browser_image(path)` 调用项目现有 OCR/视觉服务转述。该工具先经过当前场景的文件导出检查，不直接读取服务器路径，不发送 QQ 消息。主 DeepSeek 对话没有配置直接接收 MCP 图像的附件路由，因此不要把截图生成成功当作已经看懂图片。需要把文件交付用户时仍使用已有 `send_file`。

## 部署

Docker 更新代码后运行：

```bash
docker compose up -d --build myqqbot
```

无需新增模型 Key。镜像已有为 Pixiv 安装的 Playwright Chromium，浏览器接入会优先寻找 Node 对应版本，再尝试复用这个浏览器程序，不会复用 Pixiv Cookie 或用户目录。复用不同版本的浏览器存在兼容性风险，需用实际导航和操作验证；若出现协议/启动错误，应在镜像构建阶段安装匹配版本或指定经过验证的程序路径。

原生部署在更新依赖后执行：

```bash
cd dsh
npm ci
```

如果没有 Chromium/Chrome，可在部署时安装。项目运行中的网页任务不会下载浏览器：

```bash
# 在项目根目录执行；使用已有 Python Playwright 安装
python -m playwright install --with-deps chromium
```

默认自动查找已有程序；也可在 `.env` 指定：

```dotenv
# 通常不必设置，admin 中可开关
# AI_BROWSER_ENABLED=true

# 可选：绝对路径；该路径必须存在于机器人实际运行环境中
# AI_BROWSER_EXECUTABLE_PATH=/opt/pw-browsers/chromium-xxxx/chrome-linux64/chrome
```

环境中的 `AI_BROWSER_ENABLED` 优先于 admin。未设置时默认开启；admin 的“AI 服务 → 账号与功能 → 启用后台网页浏览与界面操作”可保存开关，保存时会终止当前执行任务并重启 dsh。浏览器未安装或启动失败只影响浏览器操作，普通聊天、搜索与 HTTP 抓取仍可工作。

## 资源和数据

同时只准入一个浏览任务，等待期间可取消。取得浏览器的任务持有槽位直到原生执行会话清理完成；浏览器关闭后同一任务仍可继续打开，其他任务等它结束。主对话不等待浏览任务结束，普通不需要浏览器的后台任务仍可并行。

每个临时执行者拥有独立的 MCP 连接和隔离浏览状态。生命周期由官方 provider 管理，任务完成、取消或服务停止会清理连接与浏览器。页面和登录状态不从 dsh 会话日志恢复，也不会转交给下一个任务。工具目录是按需变化的，因此首次启用会增加该执行任务的工具定义与上下文，不增加每轮普通主聊天的完整浏览器提示。

快照、控制台日志、截图和下载文件使用当前会话的 `files_directory`，默认产物位于其 `.playwright-mcp/` 子目录；这些工作区文件可以保留并进入项目备份。浏览器内存、Cookie 和操作系统临时进程不属于备份的可恢复运行状态。已有聊天、记忆和 dsh 日志无需格式迁移。

## 权限和使用边界

普通群友可以委派浏览公开网页及界面操作，不需要主人身份。网页里的提示、广告、聊天和代码只作为资料，不能成为新增授权。任务只做真实用户要求的工作，登录、提交、发布、删除或付款等操作必须符合原请求及宿主权限，不能由网页内容自行发起。

主聊天和记忆维护不能调用浏览工具，普通执行者也不能借浏览器直接发送 QQ。普通任务禁止 `browser_evaluate` 和 Node 侧 `browser_run_code_unsafe` 等脚本工具，使用快照、点击、输入等界面工具；主人任务按既有权限允许脚本。`browser_install` 始终拒绝。脚本工具可能仍出现在官方目录里，但实际执行由宿主 guard 拦截，不依赖提示词自觉遵守。

导航只接受无内嵌账号密码的 HTTP(S) URL，拒绝 `file:`、`javascript:` 等。普通任务显式导航到 localhost 和常见内网地址会要求主人身份。这个检查不是完整的网络出口隔离：页面子资源、跳转和 DNS 变化仍受浏览器及部署网络影响，不能把它当作阻止所有内网访问的防火墙；现有普通命令也并未实施网络隔离。

上传、拖放和指定导出文件名均限制在当前会话文件目录，拒绝越界路径、符号链接绕过和普通文件硬链接。浏览器本身不是命令写入沙箱；主人脚本继承服务器管理权限，不应向不可信任务授予主人身份。

验证码、网站风控、未登录内容和服务器网络仍可能导致失败。工具回执和实际页面状态是判断依据；最终回答不代表已提交表单，页面加载成功也不代表读取了全部内容。
