# 图片溯源：/find-chicken

引用一条包含图片的消息，发送 `/find-chicken`。也可以把指令和图片一起发送。
群聊和私聊均可使用，不依赖 AI 开关或 DeepSeek API Key，每次查第一张图片。
有引用时优先使用被引用的消息；引用无效或没有图片会明确提示，不会转查别的图。
不接受本地文件路径、图片网址等文字参数，也不会从其他群或私聊取图片。

搜图由后台队列处理，不阻塞其他功能。最多同时容纳10个任务（含正在处理的一项），
同一用户在同一会话默认30秒冷却。结果会发送回原会话；机器人重启会取消未完成的搜图，
不会自动重发结果，需要再次发送指令。

## 引擎和配置

admin 的功能列表中新增“鱼鱼找鸡 / 图片溯源”，可开关功能并保存搜图配置：

| 引擎 | 用途与依赖 |
| --- | --- |
| Google Lens（默认） | 广泛的相似图片和图源，需要Chromium及可访问Google的网络 |
| SauceNAO（默认） | 动漫、插画及部分其他图片的图源，无需API Key，有免费额度与频率限制 |
| trace.moe（默认） | 动画截图，提供番剧页面线索 |
| IQDB（可选） | 动漫图库反查 |
| 百度识图（可选） | 通过浏览器上传图片和提取结果 |

网络可达性以实际部署为准，均可能因限流、验证码、网站改版而失效。
无需添加Python或npm依赖，Docker镜像已有Node.js 24和Playwright Chromium。
原生部署需安装Node.js 24；Lens/百度还需要可运行的Chrome/Edge/Chromium。
可手动指定浏览器可执行文件；留空时检测常见系统路径和Playwright浏览器目录，
包括 `PLAYWRIGHT_BROWSERS_PATH`。搜图浏览器与AI浏览器、Pixiv登录的profile分开保存。

代理仅影响搜图浏览器，不改变系统设置，不自动下载、启动或管理代理软件。
支持不带用户名密码的HTTP/HTTPS/SOCKS5代理地址。
SauceNAO、trace.moe和IQDB使用Node原生HTTP请求，不继承这里的浏览器代理。
Docker里的 `127.0.0.1` 指容器自身，不代表宿主机。

单次引擎请求默认45秒，整个任务默认240秒硬超时，均可在admin调整。
“单引擎请求超时”并非该引擎全部操作的总时限，浏览器可能进行多次跳转；
整个任务超时才是最终上限。硬超时时停止进程及浏览器，并发送失败提示。
部分引擎失败时仍可返回其他引擎的结果；错误与无结果不会被当成已命中长期缓存。

## 数据和结果含义

- 图片会上传到所选搜图引擎。只在用户明确发送搜图指令时运行；不调用视觉模型或人脸识别服务。
- 支持PNG、JPEG、GIF、WebP，单张上限20 MiB；下载检查公网地址、每次重定向和实际文件头，不读取任意本地路径。
- 复用上游的相似图片解析、账号提取和名字一致性过滤。返回的是公开图源页面和候选账号，不能保证页面发布者就是图中人物；不要把候选线索当作身份核实结果。
- 有结果但没有账号时，保留最接近的图源；动画截图仍能返回番剧页面。
- 有效结果按图片内容和引擎/过滤配置缓存30天，最多500项。命中缓存仍需下载QQ图片以确认内容，但不再请求搜图引擎。
- 配置为 `data/find_chicken/config.json`，缓存为 `data/find_chicken/cache.json`，浏览器profile为 `data/find_chicken/browser-profile/`。上传用临时图片在搜图结束后删除，结果缓存不保存原图；浏览器profile会保留站点cookie与网页缓存，停用搜图后可以删除该目录清理。
- 整个data目录纳入项目备份。正在搜图时暂不允许备份/还原，避免打包运行中的浏览器状态。已有数据无需迁移；启动新增功能不会覆盖原有配置、记忆或会话。
