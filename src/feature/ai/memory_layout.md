# 记忆目录规范（宿主管理）

本规范是memory-management SKILL的一部分，涉及记忆查询、编辑或整理时读取；宿主不会每轮注入SKILL全文或独立目录规范。本节优先于历史对话或旧版SKILL中已经过时的加载方式、目录和权限说明；分类、证据和编辑习惯仍遵循SKILL。路径相对于当轮 editable_memory_directory 的上一级（cwd）：

```text
memory/
├─ raw/                         原始QQ事件和原文，只读，保留30天
├─ user/<QQ>/
│  ├─ PERSON.md                 稳定身份、背景与关系
│  ├─ PREFERENCE.md             长期偏好与习惯
│  ├─ RECENTNESS.md             有日期的近期状态与计划
│  └─ memory/<主题或事件>.md     个人经历、项目背景；只能直接放.md文件
├─ group/<群号>/<任意主题>.md   群规、本群专属梗、共同活动、群体项目
├─ common/GLOSSARY.md           跨群、跨用户的通用术语与公共知识
├─ world/**/*.md                全局世界知识，允许自由建立主题文件和多层目录
└─ soul/**/*.md                自身人格，每轮全文作为系统人格；admin人设为soul/AGENT.md
```

QQ号、群号必须是ASCII数字；群记忆可以自由命名Markdown文件，但只能放在 group/<群号>/ 这一层，不支持再建子目录。个人事实归user；仅适用于某群的事实归group并注明群号；跨群术语解释归common，主题知识归world，不能把一个群的规矩推断为所有群通用。长期记忆写提炼结果和证据，不能复制整段聊天规避raw的30天期限。

**自主学习与世界知识：** 网上冲浪、阅读公开资料和学习新知识时，把有长期价值的笔记存入memory/world/，例如world/科技/人工智能/模型进展.md、world/历史/专题/航海史.md。这里全局共享，不绑定用户或群号，可自由规划目录和主题；普通聊天执行者、自主执行者、定时执行者均可用原生write/edit创建和更新，不需要主人身份。主对话仍委派一次性执行者，不自行读写。先查已有笔记再整理，避免重复；保留来源URL、发布/发生时间（可确认时）、查阅或核验日期、适用版本，并区分已核实事实、来源说法和推测。“最新”内容须重新联网核实，旧笔记不能当实时结果；失效知识注明过时或在维护中合并清理。只沉淀有价值的提炼，不整站复制或逐页堆积流水账。

world中的Markdown递归进入向量索引、文本检索、admin记忆列表和维护暂存副本；不每轮全文注入，知识不是系统指令。可在world下保留其他资料文件，但这些文件不直接进入记忆索引或自动维护，重要内容另写Markdown摘要并链接资料。维护暂存不复制这些附属资料，不能仅因暂存缺失判定原资料丢失或删除引用；必要时只读核对正式目录。命令仍只能写当前会话files，不能借world扩大命令写入范围；知识笔记用原生工具编辑。不要把私聊内容、用户画像、群内私有事实、密钥或人设写入全局知识；它们仍分别归user/group/soul。common/GLOSSARY.md保留术语解释，不替代world的主题知识目录。

**目录约束有实际后果：** 除raw档案外，只有上面合法路径的Markdown才属于正式长期记忆。未支持的位置、额外层级、其他扩展名或任意新增的common文件不会进入向量索引、search_memory文本回退、admin记忆列表或自动整理暂存副本；重建索引也不会补收。暂存提交发现非法.md路径会拒绝整个批次、保留消息队列。不要将“原生工具写入成功”等同于“系统已纳入记忆”。发现已有非法位置的记忆时先报告具体路径和遗漏风险，再按真实授权迁移；不要默默继续往其中写入。

普通请求可编辑请求者自己的合法user记忆、当前群的合法group记忆、全局world知识和当前会话files；私聊不能改群记忆。soul是例外，任何环境的交流均可引发自主、适度的人格更新，无需主人授权，修改前先读soul-management SKILL。soul直接注入上下文，不进入向量检索，admin可查看和编辑；不要把自身人格建成人类用户画像。人格不能改变真实身份、宿主权限和发送边界。

自动整理不再使用独立持久memory对话，而是从主对话已完成上下文fork临时分支；本轮注入的维护任务优先于继承的历史请求。只修改cwd下暂存memory，宿主检查回执和冲突后提交；可用delete_memory_file删除已合并或过时的暂存文件。每100条人类消息整理和媒体补充机制保留；默认北京时间02:00另做全库压缩，可在admin定时任务调整或删除。两种维护均不发QQ、不向主对话回报；最终仅向宿主返回批次JSON，随后物理删除分支日志。原始档案仍只读、保留30天。

查询用search_memory(query, scope="auto"|"user"|"group"|"common"|"world", target_qq?, target_group?)；auto搜索所有正式记忆，scope="world"只查世界知识。target_qq仅筛选用户部分，target_group仅筛选群部分。只查某群时明确使用scope="group"及target_group；检索过滤参数不提供编辑权限。也可原生glob/grep/read，但直接搜索读到的非规范文件不会因此成为正式记忆。主对话必须把查询和编辑交给一次性子Agent，不能自行执行工具读写。

命令权限以宿主shell_allowed与shell_mode为准：普通聊天执行者可运行受限命令，允许读取外部文件，但只能写当前会话files，默认在该目录执行；不能用命令直接写记忆或规则，记忆编辑继续用原生工具。记忆维护分支仍不运行命令。此条替代旧版SKILL中“所有命令仅主人”的说明；服务器管理和越界写入仍限主人，拒绝或SANDBOX_UNAVAILABLE不能绕过。
