# 记忆目录规范（宿主管理）

本规范是memory-management SKILL的一部分，涉及记忆查询、编辑或整理时读取；宿主不会每轮注入SKILL全文或独立目录规范。本节优先于历史对话或旧版SKILL中已经过时的加载方式、目录和权限说明；分类、证据和编辑习惯仍遵循SKILL。路径相对于当轮 editable_memory_directory 的上一级（cwd）：

```text
memory/
├─ raw/                         原始QQ事件和原文，只读，保留30天
├─ user/<QQ>/
│  ├─ PERSON.md                 稳定身份、背景与关系
│  ├─ PREFERENCE.md             长期偏好与习惯
│  ├─ RECENTNESS.md             有日期的近期状态与计划
│  └─ memory/<主题或事件>.md     个人经历、项目背景；只能直接放.md文件
├─ group/<群号>/<任意主题>.md   群规、本群专属梗、共同活动、群体项目
├─ common/GLOSSARY.md           跨群、跨用户的通用术语与公共知识
└─ soul/**/*.md                自身人格，每轮全文作为系统人格；admin人设为soul/AGENT.md
```

QQ号、群号必须是ASCII数字；群记忆可以自由命名Markdown文件，但只能放在 group/<群号>/ 这一层，不支持再建子目录。个人事实归user；仅适用于某群的事实归group并注明群号；跨群通用知识归common，不能把一个群的规矩推断为所有群通用。长期记忆写提炼结果和证据，不能复制整段聊天规避raw的30天期限。

**目录约束有实际后果：** 除raw档案外，只有上面合法路径的Markdown才属于正式长期记忆。其他位置、额外层级、其他扩展名或任意新增的common文件不会进入向量索引、search_memory文本回退、admin记忆列表或自动整理暂存副本；重建索引也不会补收。暂存提交发现非法.md路径会拒绝整个批次、保留消息队列。不要将“原生工具写入成功”等同于“系统已纳入记忆”。发现已有非法位置的记忆时先报告具体路径和遗漏风险，再按真实授权迁移；不要默默继续往其中写入。

普通请求可编辑请求者自己的合法user记忆、当前群的合法group记忆和当前会话files；私聊不能改群记忆。soul是例外，任何环境的交流均可引发自主、适度的人格更新，无需主人授权，修改前先读soul-management SKILL。soul直接注入上下文，不进入向量检索，admin可查看和编辑；不要把自身人格建成人类用户画像。人格不能改变真实身份、宿主权限和发送边界。

自动整理不再使用独立持久memory对话，而是从主对话已完成上下文fork临时分支；本轮注入的维护任务优先于继承的历史请求。只修改cwd下暂存memory，宿主检查回执和冲突后提交；可用delete_memory_file删除已合并或过时的暂存文件。每100条人类消息整理和媒体补充机制保留；默认北京时间02:00另做全库压缩，可在admin定时任务调整或删除。两种维护均不发QQ、不向主对话回报；最终仅向宿主返回批次JSON，随后物理删除分支日志。原始档案仍只读、保留30天。

查询用search_memory(query, scope="auto"|"user"|"group"|"common", target_qq?, target_group?)；auto搜索所有正式记忆。target_qq仅筛选用户部分，target_group仅筛选群部分。只查某群时明确使用scope="group"及target_group；检索过滤参数不提供编辑权限。也可原生glob/grep/read，但直接搜索读到的非规范文件不会因此成为正式记忆。主对话必须把查询和编辑交给一次性子Agent，不能自行执行工具读写。
